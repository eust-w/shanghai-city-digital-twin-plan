# Security

This is a pre-release data-processing tool, not a hardened service. Run it with
least privilege and do not expose the preview HTTP server to untrusted networks.
Treat external OSM files and generated engine scripts as inputs to review.

Do not disclose credentials or internal infrastructure in public issues. For a
security issue, use GitHub's private vulnerability reporting option if available;
otherwise ask the maintainer for a private reporting channel without including
exploit details or secrets. General reproducibility bugs can use public issues.
